null_blk + F2FS · Conv vs Zoned · host-visible WAF 측정의 한계

← 실습 2로

실습 목표

이번 실습은 QEMU + null_blk + F2FS 환경에서 WAF를 계산해 보고, 처음의 직관이 실제 측정값과 어떻게 다른지 확인하는 데 목적이 있습니다.

처음에는 conventional SSD는 내부 FTL/GC 때문에 WAF가 1보다 크고, ZNS SSD는 host가 zone write 위치를 관리하므로 WAF가 1에 가까울 것이라고 예상해볼 수 있습니다. 이제 그 가설을 null_blk와 F2FS로 직접 측정해 봅니다.

왜 F2FS 환경에서 시작하는가 null_blk는 빠르고 재현 가능한 block device 실험에는 좋지만, 실제 SSD 하드웨어 FTL, NAND, device-side GC가 없습니다. 그래서 nvme smart-log로 NAND writes 같은 하드웨어 counter를 읽을 수 없고, device-internal WAF도 직접 측정할 수 없습니다. QEMU 6.0 이상의 가상 NVMe 컨트롤러로 smart-log가 완전히 지원되는 환경을 만들 수도 있지만, 현재 Ubuntu 20.04 기본 환경에서는 어렵습니다. 따라서 이번 lab3는 null_blk를 conventional/zoned 두 모드로 만들고 그 위에 F2FS를 올려, 파일시스템과 block layer에서 관찰 가능한 host-visible write를 간접 측정합니다. 실습 환경은 QEMU RAM 4GB, null_blk 2GB로 고정하고, Conv와 Zoned 장치를 동시에 올리지 않고 순차 실행합니다.
WAF = data written to flash memory / data written by the host
WAF의 기본 정의. 실제 SSD에서는 flash/NAND에 실제 기록된 양을 host가 요청한 write 양으로 나눈 값입니다.
WAFproxy = block-layer submitted write bytes (Δ write sectors × 512) / fio logical write bytes
이번 실습에서 계산하는 대체값. null_blk에는 flash memory가 없으므로 Linux block layer가 /dev/nullb*에 발행한 sector 수를 사용합니다.

Step 3.2 — common.sh: 공통 함수 라이브러리

모든 스크립트가 source하는 공통 헬퍼

장치 경로/마운트 포인트/fio 파라미터의 기본값을 정의하고, configfs 기반 null_blk 장치 생성, write_sectors 측정, F2FS sysfs/debugfs 접근, CSV 로깅을 모두 함수로 제공합니다. 환경변수로 모든 기본값을 override할 수 있습니다.

common.sh 
#!/usr/bin/env bash

set -euo pipefail

DEV="${DEV:-/dev/nullb0}"
SYS_BLOCK="${SYS_BLOCK:-/sys/block/nullb0}"
MNT="${MNT:-/mnt/f2fs-waf}"
NULLB_NAME="${NULLB_NAME:-f2fs_waf0}"
NULLB_CONFIGFS="${NULLB_CONFIGFS:-/sys/kernel/config/nullb/$NULLB_NAME}"
NULL_GB="2"
NULL_SIZE_MB="2048"
NULL_BLOCKSIZE="${NULL_BLOCKSIZE:-4096}"
ZONE_SIZE_MB="${ZONE_SIZE_MB:-64}"
ZONE_NR_CONV="${ZONE_NR_CONV:-4}"

FIO_RUNTIME="${FIO_RUNTIME:-60}"
FIO_FILL_SIZE="${FIO_FILL_SIZE:-1200M}"
FIO_FRAGMENT_FILES="${FIO_FRAGMENT_FILES:-64}"
FIO_FRAGMENT_FILE_SIZE="${FIO_FRAGMENT_FILE_SIZE:-2M}"
FIO_MEASURE_SIZE="${FIO_MEASURE_SIZE:-1200M}"
FIO_MEASURE_BS="${FIO_MEASURE_BS:-4K}"

GC_FILL_CHUNK="${GC_FILL_CHUNK:-64M}"
GC_TARGET_FREE_SEGMENTS="${GC_TARGET_FREE_SEGMENTS:-260}"
GC_MIN_AVAIL_MIB="${GC_MIN_AVAIL_MIB:-220}"
GC_FRAGMENT_FILES="${GC_FRAGMENT_FILES:-64}"
GC_FRAGMENT_FILE_SIZE="${GC_FRAGMENT_FILE_SIZE:-1M}"
GC_MEASURE_SIZE="${GC_MEASURE_SIZE:-128M}"
GC_MEASURE_BS="${GC_MEASURE_BS:-4K}"
GC_MEASURE_RW="${GC_MEASURE_RW:-randwrite}"

RESULTS_CSV="${RESULTS_CSV:-$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/results.csv}"
RUN_TAG="${RUN_TAG:-}"

need_root() {
    if [ "$(id -u)" -ne 0 ]; then
        echo "ERROR: run as root" >&2
        exit 1
    fi
}

need_cmd() {
    if ! command -v "$1" >/dev/null 2>&1; then
        echo "ERROR: missing command: $1" >&2
        exit 1
    fi
}

ensure_prereqs() {
    need_root
    need_cmd awk
    need_cmd blockdev
    need_cmd fio
    need_cmd mount
    need_cmd mountpoint
    need_cmd mkfs.f2fs
    need_cmd modprobe
    need_cmd rmdir
    need_cmd umount
}

ensure_f2fs_kernel() {
    modprobe crc32_generic || true
    if awk '$1 == "f2fs" || $2 == "f2fs" { found = 1 } END { exit !found }' /proc/filesystems; then
        return
    fi
    echo "Loading f2fs kernel module"
    modprobe f2fs
    if ! awk '$1 == "f2fs" || $2 == "f2fs" { found = 1 } END { exit !found }' /proc/filesystems; then
        echo "ERROR: f2fs is not available in this kernel" >&2
        echo "Check: grep CONFIG_F2FS_FS /boot/config-\$(uname -r)" >&2
        exit 1
    fi
}

ensure_configfs() {
    modprobe configfs || true
    mkdir -p /sys/kernel/config
    if ! mountpoint -q /sys/kernel/config; then
        mount -t configfs none /sys/kernel/config
    fi
}

load_nullblk_configfs() {
    modprobe null_blk nr_devices=0
    ensure_configfs
}

write_sectors() { awk '{ print $7 }' "$SYS_BLOCK/stat"; }
sectors_to_mib() { awk -v sectors="$1" 'BEGIN { printf "%.2f", sectors * 512 / 1024 / 1024 }'; }
bytes_to_mib()   { awk -v bytes="$1"   'BEGIN { printf "%.2f", bytes / 1024 / 1024 }'; }

print_device_stats() {
    local label="$1" sectors="$2" mib
    mib="$(sectors_to_mib "$sectors")"
    printf "%-24s %12s sectors  %10s MiB\n" "$label" "$sectors" "$mib"
}

mounted_on_mnt() { mountpoint -q "$MNT"; }

cleanup_mount() {
    if mounted_on_mnt; then
        sync
        umount "$MNT"
    fi
}

cleanup_nullblk() {
    if [ -d "$NULLB_CONFIGFS" ]; then
        if [ -w "$NULLB_CONFIGFS/power" ]; then
            echo 0 > "$NULLB_CONFIGFS/power" || true
        fi
        rmdir "$NULLB_CONFIGFS" || true
    fi
    if lsmod | awk '{ print $1 }' | grep -qx null_blk; then
        modprobe -r null_blk
    fi
}

write_configfs_attr() {
    local attr="$1" value="$2"
    if [ ! -e "$NULLB_CONFIGFS/$attr" ]; then
        echo "ERROR: null_blk configfs attribute not found: $attr" >&2
        exit 1
    fi
    echo "$value" > "$NULLB_CONFIGFS/$attr"
}

write_configfs_attr_if_exists() {
    local attr="$1" value="$2"
    if [ -e "$NULLB_CONFIGFS/$attr" ]; then
        echo "$value" > "$NULLB_CONFIGFS/$attr"
    fi
}

create_nullblk_conv() {
    load_nullblk_configfs
    mkdir "$NULLB_CONFIGFS"
    write_configfs_attr blocksize "$NULL_BLOCKSIZE"
    write_configfs_attr size "$NULL_SIZE_MB"
    write_configfs_attr memory_backed 1
    write_configfs_attr_if_exists discard 0
    write_configfs_attr power 1
}

create_nullblk_zoned() {
    load_nullblk_configfs
    mkdir "$NULLB_CONFIGFS"
    write_configfs_attr blocksize "$NULL_BLOCKSIZE"
    write_configfs_attr size "$NULL_SIZE_MB"
    write_configfs_attr memory_backed 1
    write_configfs_attr zoned 1
    write_configfs_attr zone_size "$ZONE_SIZE_MB"
    write_configfs_attr zone_nr_conv "$ZONE_NR_CONV"
    write_configfs_attr power 1
}

parse_fio_write_io_bytes() {
    local file="$1"
    if command -v jq >/dev/null 2>&1; then
        jq -r '.jobs[0].write.io_bytes' "$file"
        return
    fi
    awk '
        /"write" *: *{/ { in_write = 1 }
        in_write && /"io_bytes" *:/ {
            line = $0
            sub(/^.*"io_bytes" *: */, "", line)
            sub(/[, ].*$/, "", line)
            print line
            exit
        }
    ' "$file"
}

drop_caches() {
    sync
    if [ -w /proc/sys/vm/drop_caches ]; then
        echo 3 > /proc/sys/vm/drop_caches
    fi
}

find_f2fs_sysfs_dir() {
    local base="/sys/fs/f2fs" name
    [ -d "$base" ] || return 1
    name="$(basename "$DEV")"
    if [ -d "$base/$name" ]; then
        printf "%s/%s\n" "$base" "$name"
        return 0
    fi
    find "$base" -mindepth 1 -maxdepth 1 -type d | head -n 1
}

f2fs_sysfs_value() {
    local file="$1" dir
    dir="$(find_f2fs_sysfs_dir || true)"
    if [ -z "$dir" ] || [ ! -r "$dir/$file" ]; then
        return 1
    fi
    cat "$dir/$file"
}

free_segments() {
    local v
    v="$(f2fs_sysfs_value free_segments)" || return 1
    v="${v//[!0-9]/}"
    [ -n "$v" ] || return 1
    printf '%s\n' "$v"
}

ensure_debugfs() {
    if ! mountpoint -q /sys/kernel/debug 2>/dev/null; then
        mount -t debugfs none /sys/kernel/debug 2>/dev/null || true
    fi
}

f2fs_debugfs_status() {
    ensure_debugfs
    local f=/sys/kernel/debug/f2fs/status
    [ -r "$f" ] || return 1
    cat "$f"
}

# Echo: gc_calls gc_calls_bg blocks_moved blocks_moved_bg
f2fs_gc_counters() {
    local status
    if ! status="$(f2fs_debugfs_status 2>/dev/null)"; then
        echo "0 0 0 0"; return
    fi
    awk '
        /^GC calls:/      { calls = $3; bg = $5; gsub(/[^0-9]/, "", bg) }
        /^Try to move/    { moved = $4; mbg = $6; gsub(/[^0-9]/, "", mbg) }
        END {
            printf "%s %s %s %s\n",
                (calls == "" ? 0 : calls), (bg == "" ? 0 : bg),
                (moved == "" ? 0 : moved), (mbg == "" ? 0 : mbg)
        }
    ' <<<"$status"
}

csv_init() {
    if [ ! -f "$RESULTS_CSV" ]; then
        mkdir -p "$(dirname "$RESULTS_CSV")"
        echo "timestamp,tag,bench,mode,logical_bytes,device_bytes,waf,gc_calls_delta,gc_calls_bg_delta,blocks_moved_delta,blocks_moved_bg_delta,free_segments_after" > "$RESULTS_CSV"
    fi
}

csv_append() {
    local bench="$1" mode="$2" logical="$3" device="$4" waf="$5"
    local gc_d="$6" gc_bg_d="$7" mv_d="$8" mv_bg_d="$9" free_after="${10}"
    local ts
    ts="$(date -u +%Y-%m-%dT%H:%M:%SZ)"
    csv_init
    printf "%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s\n" \
        "$ts" "$RUN_TAG" "$bench" "$mode" \
        "$logical" "$device" "$waf" \
        "$gc_d" "$gc_bg_d" "$mv_d" "$mv_bg_d" "$free_after" \
        >> "$RESULTS_CSV"
}

avail_mib() { df -Pm "$MNT" | awk 'NR == 2 { print $4 }'; }

print_f2fs_hint_stats() {
    local dir
    dir="$(find_f2fs_sysfs_dir || true)"
    echo
    echo "F2FS sysfs snapshot:"
    if [ -z "$dir" ]; then
        echo "  unavailable"; return
    fi
    for file in gc_urgent gc_idle dirty_segments free_segments ovp_segments unusable; do
        if [ -r "$dir/$file" ]; then
            printf "  %-16s %s\n" "$file" "$(cat "$dir/$file")"
        fi
    done
}
핵심 함수 요약 create_nullblk_conv/zoned은 configfs로 장치를 생성하고, write_sectors는 /sys/block/nullb0/stat에서 스크립트 기준 awk '{ print $7 }'로 write sectors 항목을 읽습니다. 이 값은 device 내부 write가 아니라 block layer가 null_blk에 제출한 write sector입니다. f2fs_gc_counters는 debugfs에서 GC 호출/이동 블록 수를 가져와 측정 구간 동안의 cleaning 활동을 정량화합니다.
Step 3.3 — setup.sh: 환경 구성

null_blk 생성 → mkfs.f2fs → mount

인자로 conv 또는 zoned를 받아 그에 맞는 null_blk을 생성하고 F2FS를 포맷·마운트합니다. background_gc=off,noatime으로 마운트하여 측정 구간 외의 GC 노이즈를 줄입니다.

setup.sh 
#!/usr/bin/env bash

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
. "$SCRIPT_DIR/common.sh"

usage() {
    cat <<EOF
Usage: sudo $0 conv|zoned

Environment overrides:
  NULL_SIZE_MB is fixed at $NULL_SIZE_MB
  NULL_BLOCKSIZE=$NULL_BLOCKSIZE
  MNT=$MNT
  ZONE_SIZE_MB=$ZONE_SIZE_MB
  ZONE_NR_CONV=$ZONE_NR_CONV

Examples:
  sudo $0 conv
  sudo $0 zoned
EOF
}

mode="${1:-}"
case "$mode" in
    conv|zoned) ;;
    -h|--help|"") usage; exit 0 ;;
    *) usage >&2; exit 1 ;;
esac

ensure_prereqs
ensure_f2fs_kernel

if ! command -v jq >/dev/null 2>&1; then
    echo "Note: jq not found; falling back to awk JSON parsing. Install jq for robustness." >&2
fi
mkdir -p "$MNT"
cleanup_mount
cleanup_nullblk

echo "Setting up null_blk + F2FS mode=$mode"

if [ "$mode" = "conv" ]; then
    create_nullblk_conv
    mkfs.f2fs -f -o 1 "$DEV"
else
    create_nullblk_zoned
    mkfs.f2fs -f -m "$DEV"
fi

if ! mount -t f2fs -o background_gc=off,noatime "$DEV" "$MNT"; then
    echo
    echo "ERROR: mount failed. Recent kernel messages:"
    dmesg | tail -n 30 || true
    exit 1
fi

echo
echo "Mounted:"
findmnt "$MNT"

echo
echo "Block device:"
blockdev --getsize64 "$DEV" | awk '{ printf "  size: %.2f GiB\n", $1 / 1024 / 1024 / 1024 }'
if [ -r "$SYS_BLOCK/queue/zoned" ]; then
    printf "  zoned: %s\n" "$(cat "$SYS_BLOCK/queue/zoned")"
fi
if [ -r "$SYS_BLOCK/queue/chunk_sectors" ]; then
    printf "  chunk_sectors: %s\n" "$(cat "$SYS_BLOCK/queue/chunk_sectors")"
fi

print_f2fs_hint_stats

echo
echo "Ready. Run:"
echo "  sudo $SCRIPT_DIR/bench.sh $mode"

Step 3.4 — bench.sh: GC 압박형 측정

적응형 fill로 free_segments 목표치까지 채워 cleaning 유발

bench.sh는 free_segments를 목표값(GC_TARGET_FREE_SEGMENTS) 이하가 될 때까지 chunk 단위로 fill을 반복하고, fragment 후 측정 파일을 미리 layout한 뒤 그 위에 randwrite를 수행합니다. GC delta가 0이면 압박이 약한 것이므로 목표 free_segments를 더 낮춰 재시도합니다.

bench.sh 핵심 차이
  • 고정 크기 fill 대신 free_segments <= TARGET 또는 avail <= MIN_AVAIL_MIB까지 적응형 fill
  • fragment 후 측정 파일을 먼저 1MB 순차로 layout한 뒤 그 위에 randwrite 측정 (pre-layout 구간은 측정 제외)
  • 측정 size 기본값이 작음 (128MiB) — GC 압박 상태에서 ENOSPC 회피
  • 측정 구간 GC delta가 0이면 압박이 약한 것 → GC_TARGET_FREE_SEGMENTS를 더 낮춰 재시도
bench.sh 
#!/usr/bin/env bash

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
. "$SCRIPT_DIR/common.sh"

usage() {
    cat <<EOF
Usage: sudo $0 conv|zoned

Adaptive GC-pressure benchmark:
  1. Fill in chunks until F2FS free_segments reaches a target.
  2. Create small files and delete half to make invalid blocks.
  3. Pre-create a measure file, then rewrite it with randwrite so F2FS may need cleaning.

Environment overrides:
  GC_FILL_CHUNK=$GC_FILL_CHUNK
  GC_TARGET_FREE_SEGMENTS=$GC_TARGET_FREE_SEGMENTS
  GC_MIN_AVAIL_MIB=$GC_MIN_AVAIL_MIB
  GC_FRAGMENT_FILES=$GC_FRAGMENT_FILES
  GC_FRAGMENT_FILE_SIZE=$GC_FRAGMENT_FILE_SIZE
  GC_MEASURE_SIZE=$GC_MEASURE_SIZE
  GC_MEASURE_BS=$GC_MEASURE_BS
  GC_MEASURE_RW=$GC_MEASURE_RW   (randwrite recommended to invalidate blocks)
  RESULTS_CSV=$RESULTS_CSV
  RUN_TAG=$RUN_TAG
EOF
}

mode="${1:-}"
case "$mode" in
    conv|zoned) ;;
    -h|--help|"") usage; exit 0 ;;
    *) usage >&2; exit 1 ;;
esac

ensure_prereqs
if ! mounted_on_mnt; then
    echo "ERROR: $MNT is not mounted. Run setup.sh first." >&2
    exit 1
fi

WORKDIR="$MNT/waf-gc-work"
mkdir -p "$WORKDIR"

echo "Adaptive GC benchmark mode=$mode"
echo "Mount: $MNT"
echo "Target: free_segments<=$GC_TARGET_FREE_SEGMENTS, keep at least ${GC_MIN_AVAIL_MIB}MiB available"
echo "Measure: rw=$GC_MEASURE_RW size=$GC_MEASURE_SIZE bs=$GC_MEASURE_BS"
echo

drop_caches
rm -f "$WORKDIR"/fill.* "$WORKDIR"/frag.* "$WORKDIR"/measurefile

echo "[1/3] Adaptive fill"
idx=0
while :; do
    free="$(free_segments || echo 999999)"
    avail="$(avail_mib)"
    printf "  free_segments=%s avail=%sMiB\n" "$free" "$avail"

    if [ "$free" -le "$GC_TARGET_FREE_SEGMENTS" ]; then break; fi
    if [ "$avail" -le "$GC_MIN_AVAIL_MIB" ]; then
        echo "  stop fill: available space guard reached"; break
    fi

    fio --name="gc-fill-$idx" \
        --directory="$WORKDIR" --filename="fill.$idx" \
        --rw=write --bs=1M --size="$GC_FILL_CHUNK" \
        --ioengine=sync --direct=0 --fsync_on_close=1 \
        --output-format=terse >/dev/null

    idx=$((idx + 1))
    sync
done

print_f2fs_hint_stats
echo

echo "[2/3] Fragment: create small files, then delete every other file"
fio --name=gc-fragment \
    --directory="$WORKDIR" \
    --filename_format=frag.\$jobnum.\$filenum \
    --rw=write --bs=4K \
    --nrfiles="$GC_FRAGMENT_FILES" \
    --filesize="$GC_FRAGMENT_FILE_SIZE" \
    --ioengine=sync --direct=0 --fsync_on_close=1 \
    --output-format=normal

idx=0
for file in "$WORKDIR"/frag.*; do
    if [ $((idx % 2)) -eq 0 ]; then rm -f "$file"; fi
    idx=$((idx + 1))
done
sync
drop_caches
print_f2fs_hint_stats
echo

echo "[3a/3] Pre-create measure file (not measured)"
fio --name=gc-prelayout \
    --directory="$WORKDIR" --filename=measurefile \
    --rw=write --bs=1M --size="$GC_MEASURE_SIZE" \
    --ioengine=sync --direct=0 --fsync_on_close=1 \
    --output-format=terse >/dev/null
sync
drop_caches

echo "[3b/3] Measure rw=$GC_MEASURE_RW under GC pressure"
read -r gc_calls_b gc_bg_b mv_b mv_bg_b < <(f2fs_gc_counters)
before="$(write_sectors)"
fio_output="$(mktemp)"

if ! fio --name=gc-measure \
    --directory="$WORKDIR" --filename=measurefile \
    --rw="$GC_MEASURE_RW" --bs="$GC_MEASURE_BS" --size="$GC_MEASURE_SIZE" \
    --ioengine=sync --direct=1 --fsync=256 \
    --output-format=json > "$fio_output"; then
    echo "ERROR: fio measurement failed. Recent df:"
    df -h "$MNT"
    echo "fio JSON output kept at: $fio_output" >&2
    exit 1
fi

sync
after="$(write_sectors)"
read -r gc_calls_a gc_bg_a mv_a mv_bg_a < <(f2fs_gc_counters)
logical_bytes="$(parse_fio_write_io_bytes "$fio_output")"

delta_sectors=$((after - before))
device_bytes=$((delta_sectors * 512))

if [ -z "$logical_bytes" ] || [ "$logical_bytes" -eq 0 ]; then
    echo "ERROR: failed to parse fio logical write bytes" >&2
    echo "fio JSON output kept at: $fio_output" >&2
    exit 1
fi

rm -f "$fio_output"
waf="$(awk -v dev="$device_bytes" -v user="$logical_bytes" 'BEGIN { printf "%.3f", dev / user }')"

gc_calls_d=$((gc_calls_a - gc_calls_b))
gc_bg_d=$((gc_bg_a - gc_bg_b))
mv_d=$((mv_a - mv_b))
mv_bg_d=$((mv_bg_a - mv_bg_b))
free_after="$(free_segments 2>/dev/null || echo NA)"

echo
echo "Result:"
print_device_stats "before write sectors" "$before"
print_device_stats "after write sectors"  "$after"
print_device_stats "delta write sectors"  "$delta_sectors"
printf "%-24s %12s bytes    %10s MiB\n" "fio logical writes" "$logical_bytes" "$(bytes_to_mib "$logical_bytes")"
printf "%-24s %12s bytes    %10s MiB\n" "device writes"      "$device_bytes"  "$(bytes_to_mib "$device_bytes")"
printf "%-24s %12s\n" "host-visible WAF" "$waf"
printf "%-24s calls=%s (bg=%s) blocks_moved=%s (bg=%s)\n" \
    "F2FS GC delta" "$gc_calls_d" "$gc_bg_d" "$mv_d" "$mv_bg_d"

print_f2fs_hint_stats

csv_append "bench" "$mode" "$logical_bytes" "$device_bytes" "$waf" \
    "$gc_calls_d" "$gc_bg_d" "$mv_d" "$mv_bg_d" "$free_after"
echo
echo "Logged to: $RESULTS_CSV"

echo
echo "Interpretation:"
echo "  GC delta > 0 means F2FS cleaning ran inside the measured interval."
echo "  If WAF is ~1.0 with GC delta = 0, raise pressure (lower GC_TARGET_FREE_SEGMENTS)."
echo "  If it hits ENOSPC, lower GC_MEASURE_SIZE or relax GC_TARGET_FREE_SEGMENTS."

Step 3.8 — 왜 처음 가설을 그대로 결론낼 수 없는가

측정 대상의 계층 분리

측정 결과만 보면 처음의 "Conv는 크고 ZNS는 1에 가까울 것"이라는 가설을 바로 판단하고 싶어집니다. 하지만 WAF의 기본 정의는 data written to flash memory / data written by the host입니다. /sys/block/nullb*/stat은 Linux block layer가 장치에 제출한 write sector를 보여줄 뿐, 실제 SSD의 flash/NAND program 횟수나 FTL GC copy량을 보여주지 않습니다.

측정 항목null_blk + F2FS실제 SSD 내부
WAF 분자Block layer가 null_blk에 보낸 write sectorFlash/NAND에 실제 기록된 양
WAF 분모fio가 요청한 logical write bytesHost가 SSD에 요청한 write bytes
GC 주체F2FS cleaner / checkpointSSD FTL firmware
Conv SSD FTL없음있음
ZNS 내부 WAF 비교직접 비교 불가장치 counter 또는 emulator 필요
실습 결론 WAF의 정의는 data written to flash memory / data written by the host입니다. 이 실습의 결론은 "ZNS WAF가 1이고 Conv WAF가 더 크다"가 아닙니다. 결론은 null_blk와 F2FS만으로는 flash memory에 실제 기록된 양을 볼 수 없으므로, proxy WAF와 device-internal WAF를 구분해야 한다입니다. 실제 SSD 내부 WAF 비교는 다음 단계의 장치 counter 또는 emulator 실습으로 분리해야 합니다.
분석 질문

생각해보기

Q1. WAF의 정의가 flash memory에 기록된 양 / host가 기록한 양이라면, 이 실습에서 계산한 값이 SSD 내부 WAF가 아닌 이유는 무엇인가요?
힌트: null_blk에 FTL, NAND page, erase block, firmware GC가 존재하는지 생각해보세요.
Q2. bench.sh에서 GC delta가 0일 때와 0보다 클 때 WAF가 다르게 보일 수 있습니다. 어떤 동작이 이 차이를 만드나요?
힌트: GC_TARGET_FREE_SEGMENTS까지 적응형 fill을 한다는 점, 측정 구간 동안 f2fs_gc_counters의 delta가 어떻게 변하는지 비교해 보세요.
Q3. 처음 예상과 달리 Zoned F2FS에서 proxy WAF가 Conv보다 크게 나올 수 있는 이유는 무엇인가요?
힌트: zone sequential write 제약, conventional zone에 저장되는 metadata, checkpoint, discard/zone reset 처리가 host write량에 어떤 영향을 줄 수 있을까요?
Q4. 실제 Conv SSD와 ZNS SSD의 WAF를 정의대로 비교하려면 어떤 추가 측정값과 환경이 필요할까요?
힌트: host write bytes만으로는 NAND 내부 program/write 횟수를 알 수 없습니다. SMART counter, ZNS zone counter, emulator를 떠올려 보세요.
